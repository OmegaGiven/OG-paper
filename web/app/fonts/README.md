# Bundled fonts

Open-licensed fonts shipped with OG Paper (from [Google Fonts](https://github.com/google/fonts)).
The app turns each letter's outline into filled shapes, so text stays sharp at any zoom.
`fonts.json` lists them for the web app; the desktop app embeds the same files.

OG Paper is an infinite-canvas drawing app. No account or sign-in is needed, and it works fully offline.

About the empty window in the last review: we found and fixed a startup bug that left the window blank when the system withheld the first frame, because the interface's textures were lost with it. They now load whether or not that frame is shown. This build also shows a message instead of an empty window if it can't draw, and each build is now launched in its sandbox on a clean Mac before upload.

To review:
1. On launch you see the paper with the tool panel on the left, the quick toolbar along the bottom, the round tool button (bottom right) and the gear (top right). Draw on the paper; zoom with pinch or the trackpad. There is no zoom limit.
2. Portals: open the tool button, pick Portal, tap "This view" in its panel, then drag a rectangle somewhere. The rectangle shows that view live; zoom into it to go through it.
3. Settings (gear, top right) has Pages, Export, Search, Layers, Frames, Plugins and the UI settings.

Network features are optional and only used when the user chooses them: Share live (end-to-end encrypted, to a host or server the user picks) and Pages servers added by link. No data is collected; canvases stay on the device.

Why the app has the com.apple.security.network.server entitlement: Settings (gear) > Share live > "Host this canvas" makes this Mac the host of a live drawing session. The app then listens on a TCP port for incoming connections from the other people's OG Paper apps that join with the link it shows, and relays everyone's drawing to them, end-to-end encrypted. Hosting starts only when the user presses that button and stops when they press Stop hosting. To test it: press Host this canvas, copy the link, and open it from another device or another copy of OG Paper on the same network (Settings > Share live > Join).

The binary does not reference _CGSSetWindowBackgroundBlurRadius (it came from the windowing library; that call has been removed).

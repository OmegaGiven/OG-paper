# Contributing to OG Paper

Thanks for helping! The project is in its design phase, so the most useful contributions right now are:

- Feedback on [`docs/DESIGN.md`](docs/DESIGN.md) — open an issue.
- Stylus testing once Phase 0/1 builds exist (Apple Pencil, S Pen, Wacom and other pen tablets).
- Recorded pen-stroke traces for the ink test suite.

## Sign your commits (DCO)

Every commit must be signed off, certifying the [Developer Certificate of Origin](https://developercertificate.org/):

    git commit -s -m "your message"

This adds `Signed-off-by: Your Name <you@example.com>`. No CLA is required; your contribution stays under the project's licenses (MPL-2.0 for code, CC BY 4.0 for the spec), and nobody can relicense it closed.

# Trademark policy

The code is open source under MPL-2.0, but the name **"OG Paper"** and its logo identify the original project created by OmegaGiven.

- You may say your project is "based on OG Paper" or "compatible with the OG Paper format".
- If you distribute a modified version, please give it a different name so users can tell it apart from the original.
- Files in the `.ogp` format may be read and written by any software, no permission needed.

The open licenses grant copyright permissions only; they do not grant rights to the project name.
